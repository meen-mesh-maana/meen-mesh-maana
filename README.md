# مين مش معانا؟ 🕵️

لعبة جماعية مصرية أونلاين (شبيهة بـ "بكاسة"): ٣-١٠ لاعبين، واحد فيهم جاسوس مش عارف الكلمة.
من غير حسابات، من غير تحميل — لينك واحد وصحابك جوه اللعبة.

## المكونات

| الجزء | المكان | التقنية | بيتنشر فين |
|------|--------|---------|------------|
| الواجهة | `web/` | Next.js 14 (React) | Vercel |
| سيرفر الرومات | `server/` | Node + WebSocket (`ws`) | Railway |

## التشغيل محليًا

```bash
# 1) السيرفر
cd server
npm install
npm start          # http://localhost:8080

# 2) الواجهة (في تيرمنال تاني)
cd web
npm install
cp .env.example .env.local   # NEXT_PUBLIC_WS_URL=ws://localhost:8080
npm run dev        # http://localhost:3000
```

## النشر على Railway (السيرفر)

1. اعمل ريبو جديد على GitHub وارفع مجلد المشروع كله (أو `server/` لوحده).
2. في Railway: **New Project → Deploy from GitHub repo** واختار الريبو.
3. لو الرومات في مجلد فرعي: Settings → **Root Directory** = `server`.
4. Railway هيكتشف إنه Node ويشغّل `npm start` لوحده (مفيش إعدادات تانية — السيرفر بيسمع على `process.env.PORT` تلقائيًا).
5. من Settings → Networking اعمل **Generate Domain**. هيطلع لك رابط زي:
   `https://meen-mesh-maana.up.railway.app`
6. اتأكد إنه شغال: افتح الرابط في المتصفح، المفروض تشوف JSON فيه `"ok":true`.

## النشر على Vercel (الواجهة)

1. في Vercel: **Add New → Project** واستورد نفس الريبو.
2. **Root Directory** = `web`.
3. قبل الـ Deploy ضيف Environment Variable:
   - الاسم: `NEXT_PUBLIC_WS_URL`
   - القيمة: رابط Railway بصيغة WebSocket الآمن، يعني غيّر `https://` إلى `wss://`:
     `wss://meen-mesh-maana.up.railway.app`
4. Deploy. الرابط النهائي (زي `https://meen-mesh-maana.vercel.app`) هو اللي تبعته لصحابك.

> ملحوظة: المتصفحات بتمنع `ws://` من صفحة `https://` — عشان كده لازم `wss://` في الإنتاج.

## إزاي تتلعب؟

1. الهوست يعمل روم ويبعت اللينك/الكود لصحابه.
2. كل واحد يكتب اسمه ويدخل — من غير أي تسجيل.
3. الهوست يختار: طريقة اللعب (أسئلة بالدور 🎙️ أو كلام حر 📞)، عدد الجواسيس (١-٢)، التصنيف، وقت الكلام.
4. كل لاعب يشوف شاشته هو بس: الكلمة + التصنيف، أو "انت الجاسوس!".
5. **وضع الأسئلة بالدور**: دورات موجهة (الهوست يختار عددها، الافتراضي ٣) — كل لاعب بالترتيب يختار حد ويسأله سؤال **بفويس نوت** من المايك (أو مكتوب لو المايك مش متاح). بعد ما كل واحد يسأل، تبدأ دورة جديدة تلقائيًا. بعد انتهاء الدورات تتفتح **الساحة المفتوحة**: أي حد يسأل أي حد في أي ترتيب. الأسئلة كلها متاحة لإعادة السماع وقت التصويت.
6. **وضع الكلام الحر**: نقاش مفتوح في مكالمة واتساب مع تايمر جوه اللعبة.
7. التصويت: مفيش انتقال تلقائي — الجروب يقرر والهوست يدوس "ابدأ التصويت". الكل يرشّح المشتبه به. التعادل = مفيش إدانة.
8. الجاسوس عنده فرصة أخيرة يخمّن الكلمة (٤٥ ثانية).
9. النقط: اللعيبة +٢ لو مسكوا الجاسوس وفشل في التخمين، الجاسوس +٣ لو نجا أو خمّن صح.

## الاختبارات

```bash
cd server && npm test
```

سيناريو E2E كامل: ٥ لاعبين، توزيع أدوار خاص، جولتين تصويت وتخمين ونقط، فصل ورجوع لاعب، وجولة كاملة بوضع الأسئلة (صوتي + مكتوب + تخطي دور).

## حدود النسخة الحالية (v1)

- الرومات في ذاكرة السيرفر: لو السيرفر عمل restart الرومات الشغالة بتضيع (Railway بيعمل restart عند كل deploy). لو عايز ثبات أكبر، انقل الحالة لـ Redis.
- الفويس نوتس بتتخزن في الذاكرة لحد ما الجولة تخلص — حجمها محدود (٣ ميجا/رسالة).
- لو الهوست خرج نهائيًا، الهوست بينتقل لأقرب لاعب متصل.
- مفيش حماية من تخمين الكود — الكود ٥ حروف/أرقام (كافي للعب مع صحابك).
